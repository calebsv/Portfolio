# Caleb Lira | Front-End Developer — Portfólio🔥

Portfólio pessoal desenvolvido para apresentar minhas habilidades, projetos e experiência como desenvolvedor Front-End. O site foi construído com foco em performance, responsividade e uma experiência de usuário moderna.

🔗 **Acesse o projeto:** 


## 📋 Sobre o projeto

Este repositório contém o código-fonte do meu site pessoal, uma landing page de página única (single page) dividida em quatro seções principais:

- **Home** — Apresentação inicial com foto de perfil, chamada principal e botões de ação (ver projetos / baixar currículo).
- **About** — Um pouco sobre minha trajetória e números que resumem minha experiência.
- **Skills** — Stack de tecnologias que utilizo, organizada em categorias (Development, Styling UI e Tools).
- **Projects** — Vitrine com os principais projetos desenvolvidos, com links para o repositório no GitHub e para a versão publicada de cada um.

## 🚀 Tecnologias utilizadas

- **HTML5** — Estruturação semântica do conteúdo
- **Tailwind CSS** (via CDN) — Estilização utilitária e responsiva
- **CSS3** - Animações de carregamento e personalização
- **JavaScript** — Interatividade (menu mobile, carrossel de skills, animações de scroll)
- **Font Awesome** e **Bootstrap Icons** — Ícones
- **Devicon** — Ícones das tecnologias na seção de Skills
- **Google Fonts** (Poppins, Inter, Sora, Space Grotesk) — Tipografia

## ✨ Funcionalidades

- Menu de navegação responsivo com versão mobile (hambúrguer) animada
- Efeito de *glow* que acompanha o cursor na seção inicial
- Animações de entrada (*fade-in* / *reveal*) ao rolar a página
- Carrossel horizontal de tecnologias com botões de navegação
- Cards de projetos com links diretos para repositório e demonstração ao vivo
- Botão de download do currículo em PDF
- Layout mobile-first, adaptado para diferentes tamanhos de tela
